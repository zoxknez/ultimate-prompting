# Core — Final Report Schema

Deliver Markdown with at least:

1. **Executive summary** and verdict: `ready` | `ready-with-conditions` | `not-ready`
2. **Technology baseline table** (project vs resolved vs support/EOL; sources consulted)
3. **Architecture / trust-boundary map**
4. **Findings table**: `ID | P0-P3 | area | evidence status | cause | impact | repair | verification | status`
5. **Implemented changes** (if any) + regression tests
6. **Command log** (real exits only)
7. **Blocked / UNVERIFIED** areas with exact missing access
8. **Residual risk** and next owners
9. **External sources**: title, URL, version/status, access date, decision informed

If Definition of Done is incomplete, state explicitly:

> Not fully production-ready.

Then list blocking conditions.
